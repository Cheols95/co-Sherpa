# prompts/check-test-codes/

테스트 코드 점검을 위한 지침/프롬프트를 두는 곳. cycle/품질점검에서 "테스트코드 점검 시 이 하위 프롬프트의 철학을 참고하라"로 참조된다.

## 기본 철학 (프로젝트에 맞게 보강)

- **동작/계약을 검증하라, 구현 detail이 아니라.** 리팩토링으로 깨지는 테스트는 과결합 신호.
- **RED를 먼저 본다.** 실패하는 테스트 없이 통과를 주장하지 않는다.
- **경계면 교차 검증.** API 응답 ↔ 소비 측(프론트 훅/타입)을 함께 본다.
- **거짓 GREEN 경계.** mock 과다·무의미 assert·skip된 테스트를 색출.
- **커버리지는 지표지 목표가 아니다.** 핵심 분기/에러 경로 우선.

프로젝트 고유의 테스트 러너·관례가 정해지면 이 폴더에 구체 프롬프트 파일을 추가한다.
